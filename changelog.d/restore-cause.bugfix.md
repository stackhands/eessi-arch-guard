A restore that cannot run says why, with the `restore-failed` token: no private workspace (an `EESSI_ARCH_GUARD_WORKDIR` others can write, or `--strict` with neither a private `TMPDIR` nor a state directory), a restore helper that does not start, or one that gives no usable reply. It used to print "module load failed" with the node's target, the token of a module that has no build there.
