`share/sitepath.py` adds opt-in repeatable `--retain PATH` and `--check-cache` flags without modifying the shell or default output. `--retain` reports disappeared retained roots, duplicate `MODULEPATH` entries, module precedence collisions, and loaded sticky modules whose source root is absent, while `--check-cache` reports unreadable or stale cache files and differences between cached `module -t avail` and `LMOD_IGNORE_CACHE=yes module -t avail`.
