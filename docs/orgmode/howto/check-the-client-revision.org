* Check the client revision

See which CVMFS catalog revision this node has, and fail only when you name a revision it must have reached.
Publishing a repository does not by itself update a client. The client keeps the revision it mounted until it refreshes.
This reads text. It does not remount, and it does not change a repository.

** Before you start

- A file that holds the output of =cvmfs_config stat REPO=, or the same lines saved from the client.
  The revision is the line =Revision: N=. Some clients print =Catalog revision: N= or =Repository revision: N=.
- Python 3.9 or newer. The script uses the standard library.
- A checkout of this repository, or a `pip install .`, which installs the script at `$PREFIX/share/eessi-arch-guard/cvmfsrev.py` (`PREFIX` is `sys.prefix`).

** Steps

1. Save the client's status and read the number:

   #+begin_src bash
   cvmfs_config stat software.eessi.io > /tmp/cvmfs-stat.txt
   python3 share/cvmfsrev.py --stat /tmp/cvmfs-stat.txt
   #+end_src

   With no =--min=, the script prints =revision N= and exits 0, whatever N is.
   That is the whole of the default. Nothing is compared.

2. Gate a job on a revision you just published:

   #+begin_src bash
   python3 share/cvmfsrev.py --stat /tmp/cvmfs-stat.txt --min 1200
   #+end_src

   Exit 0 when the client is at 1200 or newer. Exit 1 when it is older, and the line says =behind=.
   Refresh the client, then read the status again. The script does not refresh it.

** If it fails

| Message | Cause | What to do |
|---|---|---|
| =cvmfsrev.py: no revision in the stat output= | The file has none of the three revision lines. | Point =--stat= at the output of =cvmfs_config stat=. |
| =behind revision N is older than M= | The client catalog is older than =--min=. | Refresh the client and take a new stat file. |
| =cvmfsrev.py: cannot read PATH= | The stat file is missing. | Write it first. The script does not run =cvmfs_config= itself. |
| =cvmfsrev.py: --min must be zero or more= | =--min= was negative. | Pass the revision you published, which is zero or more. |
